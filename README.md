# Glider Copilot

Aide au vol à voile sur smartphone Android — **aide secondaire**, qui ne remplace ni l'instrumentation de bord, ni le FLARM, ni la veille extérieure.

MVP en cours : écran **Prévol** (météo réelle precog, planeur, club) et écran **Vol**.

- Plan et suivi de session : [`docs/HANDOFF.md`](docs/HANDOFF.md)
- Données météo : API precog (Météo-France, ECMWF) — attribution affichée dans l'app.
- Trafic : Open Glider Network (ODbL) — à venir.
